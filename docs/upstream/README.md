# Retired upstream skill resources

These files preserve upstream history. They are not current GPT-6 workflow instructions and are excluded from the Codex package. Some recommend rules that the maintained shared workflow policy deliberately replaces.

Harness adapters still used by legacy source integrations remain at their original paths under `skills/using-superpowers/references/`; they are also excluded from the portable package. Legacy graph rendering tools remain available for their existing source tests. The explicit distribution list is `packaging/codex-files.json`.
